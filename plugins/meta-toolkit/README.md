# meta-toolkit

Meta-tools for creating and generating Claude Code extensions.

## Commands

- `/meta-toolkit:create-command` — Scaffold a new plugin command
- `/meta-toolkit:create-subagent` — Scaffold a new subagent
- `/meta-toolkit:generate-toolkit` — Generate a project-specific skill toolkit

## Install

```
/plugin marketplace add GoogilyBoogily/googilyboogily-claude-power-tools --plugin meta-toolkit
```
