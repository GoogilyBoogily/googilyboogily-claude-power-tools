# architecture-toolkit

Meta-tools for creating commands, subagents, generating project toolkits, and deep research.

## Install

```
/plugin install architecture-toolkit@googilyboogily-claude-power-tools
```

## Commands

### Meta (`meta/`)
- **create-command** -- Create a new Claude Code slash command with full feature support
- **create-subagent** -- Create a specialized AI subagent following domain expert principles
- **generate-toolkit** -- Analyze a project and dynamically generate tailored skills and subagents

### Research
- **research** -- Deep research with parallel subagents and automatic citations

## Usage

```
/architecture-toolkit:meta:create-command
/architecture-toolkit:meta:create-subagent
/architecture-toolkit:meta:generate-toolkit
/architecture-toolkit:research "How does React Server Components caching work?"
```
