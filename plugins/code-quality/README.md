# code-quality

Code quality commands for review, dead code detection, and validation.

## Commands

- `/code-quality:code-review` — Deep code review with actionable feedback
- `/code-quality:dead-code` — Detect and report unused code
- `/code-quality:validate-and-fix` — Validate code and auto-fix issues

## Install

```
/plugin marketplace add GoogilyBoogily/googilyboogily-claude-power-tools --plugin code-quality
```
