# typescript-agents

TypeScript expert subagents for Claude Code.

## Agents

- **typescript-expert** — Type errors, migration strategies, monorepo config, architectural patterns
- **build-expert** — tsconfig compilation, module resolution, build performance, project references
- **type-expert** — Complex generics, conditional/mapped/template literal types, type-level programming

## Install

```
/plugin marketplace add GoogilyBoogily/googilyboogily-claude-power-tools --plugin typescript-agents
```
