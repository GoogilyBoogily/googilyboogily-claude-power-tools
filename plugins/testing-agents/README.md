# testing-agents

Testing expert subagents for Claude Code.

## Agents

- **testing-expert** — Test failures, flaky tests, mocking strategy, coverage, Jest/Vitest/Testing Library
- **e2e-playwright-expert** — Playwright E2E tests, cross-browser automation, visual regression, CI/CD

## Install

```
/plugin marketplace add GoogilyBoogily/googilyboogily-claude-power-tools --plugin testing-agents
```
