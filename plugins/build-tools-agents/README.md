# build-tools-agents

Build tool expert subagents for Claude Code.

## Agents

- **vite-expert** — Vite dev server, HMR, build optimization, plugin development, SSR
- **webpack-expert** — Webpack configuration, code splitting, module federation, plugins/loaders

## Install

```
/plugin marketplace add GoogilyBoogily/googilyboogily-claude-power-tools --plugin build-tools-agents
```
