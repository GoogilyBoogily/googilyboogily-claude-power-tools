# product-agents

Product expert subagents for Claude Code.

## Agents

- **product-manager** — Feature prioritization, user stories, roadmap planning, product-market fit
- **project-manager** — Task breakdown, timeline estimation, risk management, dependency tracking
- **ux-researcher** — Usability analysis, user interviews, heuristic evaluation, design recommendations

## Install

```
/plugin marketplace add GoogilyBoogily/googilyboogily-claude-power-tools --plugin product-agents
```
