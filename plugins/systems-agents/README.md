# systems-agents

Systems programming expert subagents for Claude Code.

## Agents

- **rust-engineer** — Ownership/borrow checker, async Rust, unsafe code, Cargo workspaces
- **game-developer** — Game architecture, ECS patterns, render pipelines, physics, multiplayer
- **performance-engineer** — Profiling, bottleneck identification, load testing, latency reduction

## Install

```
/plugin marketplace add GoogilyBoogily/googilyboogily-claude-power-tools --plugin systems-agents
```
