# react-agents

React expert subagents for Claude Code.

## Agents

- **react-expert** — Component issues, hook errors, re-rendering bugs, state management, hydration
- **react-performance-expert** — Slow renders, bundle bloat, memory leaks, Core Web Vitals optimization

## Install

```
/plugin marketplace add GoogilyBoogily/googilyboogily-claude-power-tools --plugin react-agents
```
