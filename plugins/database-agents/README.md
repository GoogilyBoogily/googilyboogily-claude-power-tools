# database-agents

Database expert subagents for Claude Code.

## Agents

- **database-expert** — General database schema design, query performance, connection management
- **postgres-expert** — PostgreSQL query optimization, JSONB, indexing, partitioning, replication
- **mongodb-expert** — MongoDB document modeling, aggregation pipelines, sharding, replica sets
- **optimizer** — Cross-database query optimization and performance tuning

## Install

```
/plugin marketplace add GoogilyBoogily/googilyboogily-claude-power-tools --plugin database-agents
```
