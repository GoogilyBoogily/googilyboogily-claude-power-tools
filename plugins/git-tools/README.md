# git-tools

Git workflow commands for Claude Code.

## Commands

- `/git-tools:commit` — Smart git commit with conventional messages
- `/git-tools:checkout` — Branch checkout with safety checks
- `/git-tools:status` — Enhanced git status overview
- `/git-tools:push` — Push with pre-push validation
- `/git-tools:ignore-init` — Initialize .gitignore for your project type

## Install

```
/plugin marketplace add GoogilyBoogily/googilyboogily-claude-power-tools --plugin git-tools
```
