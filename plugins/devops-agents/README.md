# devops-agents

DevOps expert subagents for Claude Code.

## Agents

- **devops-expert** — DevOps and infrastructure router, CI/CD, deployment
- **docker-expert** — Dockerfile optimization, container security, Docker Compose, multi-stage builds
- **git-expert** — Git workflow, merge conflicts, rebase, history rewriting, repository recovery
- **github-actions-expert** — GitHub Actions workflows, CI/CD pipelines, custom action development

## Install

```
/plugin marketplace add GoogilyBoogily/googilyboogily-claude-power-tools --plugin devops-agents
```
