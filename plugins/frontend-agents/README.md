# frontend-agents

Frontend expert subagents for Claude Code.

## Agents

- **accessibility-expert** — WCAG 2.1/2.2 compliance, WAI-ARIA, screen readers, keyboard navigation
- **css-styling-expert** — CSS architecture, layout bugs, responsive design, CSS-in-JS, themes
- **flutter-expert** — Flutter 3+ widget composition, state management, platform channels, animations

## Install

```
/plugin marketplace add GoogilyBoogily/googilyboogily-claude-power-tools --plugin frontend-agents
```
