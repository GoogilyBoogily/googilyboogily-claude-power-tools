# ai-agents

AI/ML expert subagents for Claude Code.

## Agents

- **ai-sdk-expert** — Vercel AI SDK v5: streaming, model integration, tool calling, hooks
- **llm-architect** — LLM system architecture: RAG pipelines, prompt engineering, model serving
- **prompt-engineer** — Prompt design, optimization, few-shot examples, evaluation frameworks

## Install

```
/plugin marketplace add GoogilyBoogily/googilyboogily-claude-power-tools --plugin ai-agents
```
